## 🌐 Nginx Docker 접속 로그 분석 및 실시간 IP 확인 (13:43:34)

**USER**: nginx 도커 어세스 로그에서 외부에서 접속한 ip 별로 접속 로그를 보고 싶은데 어떻게 해야함?

**ASSISTANT**: Cloudflare와 Nginx Docker 조합에서 접속 IP를 분석하는 방법을 안내해 드립니다.  
1. **명령어**: `docker logs nginx 2>&1 | awk '{print $1}' | sort | uniq -c | sort -nr | head -n 20`
2. **Cloudflare 주의사항**: 사용자 Real IP를 보려면 `nginx.conf`에 `real_ip_header CF-Connecting-IP;` 설정이 필요합니다.
3. **분석**: `awk`를 이용해 첫 번째 필드(IP)를 추출하고 정렬하여 접속 횟수를 카운트합니다.
